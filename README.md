# Привет! Я Екатерина — тестировщик

Я занимаюсь ручным тестированием и понемногу автоматизирую. Люблю делать мир менее раздражающим и более удобным (и да, даже маленькое исправление бага может сильно влиять на пользовательский опыт).

## Чем занимаюсь

- Ручное тестирование: чек‑листы, тест‑кейсы, исследовательское тестирование.
- Валидация полей: длина, граничные значения, невалидные символы, форматы.
- Работа с требованиями: матрица покрытия, критерии выхода, статусы баг‑репортов.
- Работа с тестовой документацией: составление, корректировка, актуализация кейсов для наборов смоук и регресса.
- API‑тесты в Postman: сценарии, коды ответов (400, 500), обработка ошибок.
- Git: работа с репозиториями, ветками, пулл-реквестами, коммиты, пуш изменений.

## Навыки и стек

- Тестирование: тест-план, матрица покрытия требований, баг‑репорты, исследовательское тестирование.
- HTTP/REST: GET, POST, PUT, PATCH; коды состояния; сценарии валидации.
- Инструменты: IDEA (тесты к API), Git, Kibana (просмотр логов на dev/stage/prod‑like стендах), Postman.
- SQL: базовые выборки, создание таблиц, их редактирование.
- Документация: статусы дефектов, критерии выхода из тестирования, описание окружений.
